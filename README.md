# Password Manager

A simple GUI password manager with random password generation.

## Usage

1. Run the application:
```bash
python main.py
```

2. Enter website, email (defaults to "email@domain.com"), and either:
   - Type your password, or
   - Click "Generate Password" for a random one

3. Click "Add" to save the password (stored in `data.txt`)

Passwords are saved in the format: `website | email | password`
